# Abierto-Cerrado (OCP)

## La idea

Para agregar algo nuevo, se crean clases nuevas en vez de cambiar las que ya funcionan.

 Cómo se hace en este código

 Figura es la clase base.
 Cuadrado y Rectangulo son figuras con su propia área
  La función mostrarArea sirve para cualquier figura.

Si se quiere agregar un Triangulo, solo se crea la clase nueva, Nada de lo que ya estaba se modifica
